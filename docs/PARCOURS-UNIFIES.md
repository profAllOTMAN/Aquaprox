# Parcours de diagnostic unifiés

Les quatre zones utilisent le même moteur d’enquête : bâtiment → zoom vidéo → scène avec « + » sans légende → rapprochement vers l’objet → question de constat → explication → question sur l’intervention → action(s) → comparaison Avant/Après. Les libellés restent accessibles aux lecteurs d’écran ; aucun nom de zone ou d’anomalie n’est affiché sous les marqueurs.

Le point Logements est placé à x = 48 %, y = 56 %, au centre du cercle indiqué sur la capture client. Les points d’observation et les images de chaque enquête sont définis dans les fichiers de scène de leur zone.

| Zone | Enquêtes |
| --- | --- |
| Chaufferie | Dépôts ferreux, pression, calcaire, corrosion |
| Logement | Radiateur emboué, douche entartrée, ECS insuffisamment chaude |
| Gaines techniques | Déséquilibre des débits |
| Toiture | Glycol dégradé, PAC en défaut |

Chaque enquête comporte deux questions, des indices après erreur et une explication après réponse juste. Les interventions effectuées restent dans le décor. Le retour au bâtiment conserve la progression par zone.

La vue thermique du radiateur est une surcouche pédagogique sur le radiateur réel du décor ; elle apparaît après sélection. Le diagnostic ECS distingue explicitement une température insuffisante d’une contamination confirmée. Le kit PROBIO est présenté comme moyen de désinfection après contrôle, avec correction de la cause et suivi de l’installation.

Le parcours glycol montre un état opérationnel dès la présentation de la solution : plus de rejet à la soupape, bac vide et propre, voyant vert. Le zoom toiture dure exactement 3 s, en 1920 × 1080, avec une image de fin calée sur le décor interactif. Une seule génération Kling 3.0 Pro a consommé 5,25 crédits Higgsfield sur l’enveloppe maximale de 200 crédits. Les images fixes sont produites avec ImageGen intégré.

Les détails des médias et prompts sont dans `TOITURE-SCENE.md` et `CHAUFFERIE-SCENE-REFERENCE.md`.
